# Icons

`tern-inbox`, `tern-archive`, `tern-sidebar`, `tern-sun` and `tern-moon` are Tern's own.

Every other `tern-*-symbolic.svg` here is a copy of the icon of the same name without the
`tern-` prefix from GNOME's **Adwaita icon theme** 51 (https://gitlab.gnome.org/GNOME/adwaita-icon-theme),
used under its LGPL-3.0 option (the theme is CC-BY-SA-3.0 OR LGPL-3.0). They're bundled under
their own names so the desktop's icon theme can't swap them: GTK looks in the desktop's theme
(Breeze on KDE) before Tern's resources, and Breeze draws some of these very differently
(md/DEBUG.md 2026-11-17, KDE finding 1).
